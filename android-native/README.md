# Waqt Android family test
Native Android wrapper around the existing web UI, using AndroidX WebViewAssetLoader and an origin-restricted message bridge (not Capacitor). Website remains static. Android 8+ minimum. Gradle CI bundles licensed Azan recordings, so no user upload is needed. Audio conversion: mono MP3 from original recordings, see AUDIO.md. Original Fajr recording contains the live event audio and needs listening review before release.
Exact user-approved alarms use AlarmManager.setAlarmClock; a foreground media service plays the bundled recording. One next alarm at a time; persisted timetable, re-arm on boot after first unlock, clock change and permission grant. Native status distinguishes enabled from ready. Users must select correct Malaysian zone, load annual data online, enable Azan and approve Alarms & reminders and notifications. Refresh timetable before expiry. No guarantee after force-stop, while powered off, before first unlock, with zero alarm volume, DND, or OEM-specific restrictions. Check volume and system permissions. No iOS build yet.
Build via Actions > Android family test build. Download debug APK artifact only for personal testing. Do not distribute widely until tested, signed with a stable release key, and reviewed. Test all 5 prayers, lock screen, airplane mode, reboot, zone change, disabled alarms, permission revocation, DND, audio source quality, and prayer times against JAKIM. No real-device or production certification yet.
